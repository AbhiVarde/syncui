#### Prerequisites

An existing React project with a package manager installed.

#### Install dependencies

<PackageManagerTabs
  npm="npm install @mui/material @emotion/react @emotion/styled motion react-icons"
  yarn="yarn add @mui/material @emotion/react @emotion/styled motion react-icons"
  pnpm="pnpm add @mui/material @emotion/react @emotion/styled motion react-icons"
  bun="bun add @mui/material @emotion/react @emotion/styled motion react-icons"
/>

#### Run dev

<PackageManagerTabs
  npm="npm run dev"
  yarn="yarn dev"
  pnpm="pnpm dev"
  bun="bun dev"
/>

Works the same whether you're on Vite, Create React App, or a custom setup.

You're all set. Add any component, block, or chart with the CLI, or copy the code straight from [Components](/components), [Blocks](/blocks), and [Charts](/charts).
