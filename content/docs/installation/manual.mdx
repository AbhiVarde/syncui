#### Prerequisites

You'll need an existing React project with a package manager installed (npm, yarn, pnpm, or bun).

#### Install dependencies

<PackageManagerTabs
  npm="npm install @mui/material @emotion/react @emotion/styled motion react-icons"
  yarn="yarn add @mui/material @emotion/react @emotion/styled motion react-icons"
  pnpm="pnpm add @mui/material @emotion/react @emotion/styled motion react-icons"
  bun="bun add @mui/material @emotion/react @emotion/styled motion react-icons"
/>

#### Use the CLI

<PackageManagerTabs
  npm="npx @abhivarde/syncui@latest add hero"
  yarn="yarn dlx @abhivarde/syncui@latest add hero"
  pnpm="pnpm dlx @abhivarde/syncui@latest add hero"
  bun="bunx --bun @abhivarde/syncui@latest add hero"
/>

Add a specific variant with `name/variant`, for example `hero/left`. Pass `--skip-install` if you'd rather manage dependencies yourself.

#### Start development

<PackageManagerTabs
  npm="npm start"
  yarn="yarn start"
  pnpm="pnpm start"
  bun="bun start"
/>

Or if using Vite or a custom setup:

<PackageManagerTabs
  npm="npm run dev"
  yarn="yarn dev"
  pnpm="pnpm dev"
  bun="bun dev"
/>
