#### Prerequisites

You'll need an existing Next.js project with a package manager installed (npm, yarn, pnpm, or bun).

#### Initialize Sync UI

<PackageManagerTabs
  npm="npx @abhivarde/syncui@latest init"
  yarn="yarn dlx @abhivarde/syncui@latest init"
  pnpm="pnpm dlx @abhivarde/syncui@latest init"
  bun="bunx --bun @abhivarde/syncui@latest init"
/>

This creates a `components.json` config and installs the base dependencies.

#### Wrap your app in ThemeProvider

App Router needs a client boundary at the provider level.

```jsx
"use client";
import { ThemeProvider, createTheme, CssBaseline } from "@mui/material";

const theme = createTheme({
  palette: { mode: "dark" },
  typography: { fontFamily: "inherit" },
});

export function Providers({ children }) {
  return (
    <ThemeProvider theme={theme}>
      <CssBaseline />
      {children}
    </ThemeProvider>
  );
}
```

<br />

```jsx
import { Providers } from "@/components/providers";

export default function RootLayout({ children }) {
  return (
    <html lang="en">
      <body>
        <Providers>{children}</Providers>
      </body>
    </html>
  );
}
```

<br />

Using Pages Router instead? See [Manual Setup](/docs/installation/manual).

Any Sync UI component used inside the App Router also needs `"use client"` at the top.

#### Add your first component

<PackageManagerTabs
  npm="npx @abhivarde/syncui@latest add hero"
  yarn="yarn dlx @abhivarde/syncui@latest add hero"
  pnpm="pnpm dlx @abhivarde/syncui@latest add hero"
  bun="bunx --bun @abhivarde/syncui@latest add hero"
/>

Add a specific variant with `name/variant`, for example `hero/left`. Dependencies install automatically, pass `--skip-install` to skip.

#### Start development

<PackageManagerTabs
  npm="npm run dev"
  yarn="yarn dev"
  pnpm="pnpm dev"
  bun="bun dev"
/>

Open [http://localhost:3000](http://localhost:3000) in your browser.
