#### Prerequisites

An existing Next.js project with a package manager installed.

#### Initialize

<PackageManagerTabs
  npm="npx @abhivarde/syncui@latest init"
  yarn="yarn dlx @abhivarde/syncui@latest init"
  pnpm="pnpm dlx @abhivarde/syncui@latest init"
  bun="bunx --bun @abhivarde/syncui@latest init"
/>

Creates `components.json` and installs base dependencies.

#### Wrap your app

App Router needs a client boundary.

```jsx
"use client";
import { ThemeProvider, createTheme, CssBaseline } from "@mui/material";

const theme = createTheme({ palette: { mode: "dark" } });

export function Providers({ children }) {
  return (
    <ThemeProvider theme={theme}>
      <CssBaseline />
      {children}
    </ThemeProvider>
  );
}
```

```jsx
import { Providers } from "@/components/providers";

export default function RootLayout({ children }) {
  return (
    <html lang="en">
      <body>
        <Providers>{children}</Providers>
      </body>
    </html>
  );
}
```

Using Pages Router? See [Manual](/docs/installation/manual). Any Sync UI component inside App Router also needs `"use client"`.

#### Run dev

<PackageManagerTabs
  npm="npm run dev"
  yarn="yarn dev"
  pnpm="pnpm dev"
  bun="bun dev"
/>

Open [http://localhost:3000](http://localhost:3000).

You're all set. Add any component, block, or chart with the CLI, or copy the code straight from [Components](/components), [Blocks](/blocks), and [Charts](/charts).
