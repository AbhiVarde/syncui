#### Prerequisites

You'll need an existing Vite project with a package manager installed (npm, yarn, pnpm, or bun).

#### Initialize Sync UI

<PackageManagerTabs
  npm="npx @abhivarde/syncui@latest init"
  yarn="yarn dlx @abhivarde/syncui@latest init"
  pnpm="pnpm dlx @abhivarde/syncui@latest init"
  bun="bunx --bun @abhivarde/syncui@latest init"
/>

This creates a `components.json` config and installs the base dependencies.

#### Wrap your app in ThemeProvider

```jsx
import React from "react";
import ReactDOM from "react-dom/client";
import { ThemeProvider, createTheme, CssBaseline } from "@mui/material";
import App from "./App";

const theme = createTheme({ palette: { mode: "dark" } });

ReactDOM.createRoot(document.getElementById("root")).render(
  <ThemeProvider theme={theme}>
    <CssBaseline />
    <App />
  </ThemeProvider>,
);
```

#### Add your first component

<PackageManagerTabs
  npm="npx @abhivarde/syncui@latest add hero"
  yarn="yarn dlx @abhivarde/syncui@latest add hero"
  pnpm="pnpm dlx @abhivarde/syncui@latest add hero"
  bun="bunx --bun @abhivarde/syncui@latest add hero"
/>

Add a specific variant with `name/variant`, for example `hero/left`. Dependencies install automatically, pass `--skip-install` to skip.

#### Start development

<PackageManagerTabs
  npm="npm run dev"
  yarn="yarn dev"
  pnpm="pnpm dev"
  bun="bun dev"
/>

Open [http://localhost:5173](http://localhost:5173) in your browser.
