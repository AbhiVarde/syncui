#### Prerequisites

An existing TanStack Start project with a package manager installed.

#### Initialize

<PackageManagerTabs
  npm="npx @abhivarde/syncui@latest init"
  yarn="yarn dlx @abhivarde/syncui@latest init"
  pnpm="pnpm dlx @abhivarde/syncui@latest init"
  bun="bunx --bun @abhivarde/syncui@latest init"
/>

Creates `components.json` and installs base dependencies.

#### Wrap your app

TanStack Start renders through a root route.

```jsx
// app/routes/__root.tsx
import { ThemeProvider, createTheme, CssBaseline } from "@mui/material";

const theme = createTheme({ palette: { mode: "dark" } });

function RootDocument({ children }) {
  return (
    <html>
      <head>
        <Meta />
      </head>
      <body>
        <ThemeProvider theme={theme}>
          <CssBaseline />
          {children}
        </ThemeProvider>
        <Scripts />
      </body>
    </html>
  );
}
```

Keep `createTheme` static. Runtime values like `Date.now()` will cause a hydration mismatch.

#### Run dev

<PackageManagerTabs
  npm="npm run dev"
  yarn="yarn dev"
  pnpm="pnpm dev"
  bun="bun dev"
/>

Open [http://localhost:3000](http://localhost:3000).

You're all set. Add any component, block, or chart with the CLI, or copy the code straight from [Components](/components), [Blocks](/blocks), and [Charts](/charts).
