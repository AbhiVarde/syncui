Sync UI gives you components, blocks, charts, and templates built with MUI and Motion. Copy the code, install with the CLI, connect via MCP, or use the agent skill, your agent handles the rest.

#### Pick your framework

<FrameworkGrid />

Every guide covers the same three steps: initialize, wrap your theme, run dev. Pick your framework and follow it end to end.

#### Add anything with the CLI

Once initialized, add any component, block, or chart the same way, on any framework.

<PackageManagerTabs
  npm="npx @abhivarde/syncui@latest add hero"
  yarn="yarn dlx @abhivarde/syncui@latest add hero"
  pnpm="pnpm dlx @abhivarde/syncui@latest add hero"
  bun="bunx --bun @abhivarde/syncui@latest add hero"
/>

Use `name/variant` for a specific style, for example `hero/left`.
